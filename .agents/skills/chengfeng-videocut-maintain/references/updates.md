# 更新模式

先读[公共接入](shared/plugin-access.md)。只处理用户所选组件，不建项目、不转录、不导出，不自动打开另一工作台。首次安装或新增能力使用受信安装说明；普通故障先按[排查](diagnose.md)定位，不以重装代替诊断。

## 先分清更新谁

| 对象 | 只读证据 | 更新入口 |
|---|---|---|
| 独立 Skill | 安装记录、id/version/摘要、固定来源、实际 SKILL.md | 对应固定发行附带的已核验安装说明/安装器 |
| 宿主 Plugin | 宿主支持接口返回的 selector、版本、来源、enabled/加载状态 | 该宿主原生管理能力 |
| Runtime | 已确认启动器的 --help、doctor --json、workbench commands；有明确 endpoint 才 connect | 匹配渠道/平台的 Runtime 安装说明与受信安装器 |

只说检查时先读本地身份，可按请求查询候选，但不下载激活。更新一个对象不证明另两个也更新；缺 MCP 不等于 CLI 不可用。

## 独立 Skill

1. 从安装记录或用户指定来源确认包、目标与同名提供者，不从 cwd 猜仓库。
2. 核对固定 commit/版本、包内路径、摘要、兼容要求、许可与安装影响；main/latest 不算锁定身份。计划仓库名、本地候选的 `remoteCommit=null` 不是公开产物，不能编造 npx 下载命令。
3. 展示当前 → 候选身份、来源、写入范围与回退方式；只有更新授权覆盖这些对象和影响才执行。先保留本地修改，不因有新版本覆盖。
4. 当前独立包安装器只支持首装、完全一致复用和 doctor，没有自动升级/卸载。冲突保留原包，提供迁移计划，不先删目录绕过拒绝，也不假装支持整套回滚。
5. 安装后核对实际字节、身份和路径，再看宿主是否真正加载；文件安装不等于 loaded 或 Runtime ready。新旧同名提供者不默认同时启用。

## Plugin、Runtime 与受管依赖

Plugin 仅在确实属于该渠道时使用当前宿主已支持的查询/安装方法：先读帮助与实际 selector/source，再按已确认范围调用；不猜命令、marketplace 或直接写 cache。旧原生安装桥仅在用户选择且该发行实测支持时按随包合同使用，保留 approvalDigest/固定资产 SHA 边界。独立包不携带 MCP，不要求有 Codex CLI。

Runtime 按[CLI 合同](shared/runtime-cli.md)查真实入口与 commands；不扫描端口、不用 service ensure 做探测、不复制注册。准备兼容受管 Bun/FFmpeg/FFprobe，不要求系统 PATH；渲染浏览器按实际导出合同处理，不因查更新下载 Chrome。版本相同不等于 API 相同；workbench 没有 install/repair，缺验证资产或渠道不匹配就停止。

安装/修复不碰素材、工程、Cuts/EDL、词典或其他包。转录凭据只经授权用已验证配置入口设置，不输出密钥，也不靠收费转录检测就绪。提交/激活结果未知时先查原记录，不反复执行副作用。

## 报告

分开列出当前来源/版本、候选、授权范围、实际安装、宿主加载、CLI/服务能力、回退状态及未验证项。失败区分权限、网络、版本、依赖与加载，不循环升级全部包。
